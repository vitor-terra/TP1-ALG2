Para executar o projeto:

1. Inicie um abiente virtual de Python (caso deseje).
2. Execute o comando (na raiz do projeto) 'pip install -r requirements.txt'.
3. Execute o comando (na raiz do projeto) 'python UI.py'.
4. Em um navegador, abra o link 'http://127.0.0.1:8050/'.
5. Para melhores resultados, utilize um navegador baseado em Chromium (Google Chrome, Opera, Microsoft Edge, etc) e ligue a aceleração gráfica.
6. Escolha a quantidade de motoristas que se deseja gerar na caixa indicada e pressione o botão "Gerar Motoristas".
![alt text](image.png)
7. Escolha o restaurante e a distância máxima de busca de motoristas nas caixas indicadas. Opcionalmente, pode-se escolher também um tempo máximo esperado de chegada para os motoristas. Pressione o botão "Buscar".
![alt text](image-1.png)
8. Serão exibidos no mapa os motoristas em distância hábil em vermelho e os demais em cinza. Para verificar o tempo de chegada ou a distância exata de um motorista com marcador vermelho, segure o ponteiro do mouse sobre seu respectivo marcador
